BUNGA MANIKANTA — PORTFOLIO WEBSITE

Files
- index.html: website content
- style.css: responsive styling and colour theme
- script.js: mobile navigation

HOW TO USE
1. Extract this ZIP file.
2. Open index.html in a browser to preview the website.
3. Before publishing, open index.html and replace YOUR_EMAIL@gmail.com with the correct email address.
4. The phone number is not printed anywhere on the page; it is only attached to the Call me button.

COLOUR PALETTE
- Powder blue: #B9DCF4
- Pure white: #FFFFFF
- Vibrant racing orange: #FF5A1F
- Deep ink: #142638

PUBLISHING
Upload index.html, style.css and script.js together to GitHub Pages or another static website host.
